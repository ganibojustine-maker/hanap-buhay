# HANAPBUHAY — Clickable Prototype

Open `index.html` in any browser (double-click). No install, no backend, no internet needed.

Screens (also reachable from the floating bar at the bottom-right):
1. Landing / Home  2. Worker Login / Sign Up  3. Worker Dashboard  4. Job Search / Results
5. Job Details  6. Skills Passport  7. Training & Courses  + Mobile Responsive Preview (#/mobile)

Working interactions: login validation, show/hide password, job filters + sorting + search,
favorite hearts, Apply modal (state persists), Save job, Skills Passport tabs + Add Skill,
Training tabs + Enroll, profile menu / logout. All data is mock data (js/app.js).
Photos were cropped from design-reference.png, so swap `assets/*.jpg` for real photos later.

The original React + PHP code (frontend/, backend/) is untouched.
